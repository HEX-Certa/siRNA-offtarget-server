# 原理与工作方式

本文按当前代码说明本服务如何计算脱靶，以及与文献 / siDirect 口径的对应关系。HTTP 字段见 [接入指引](接入指引.md)。实现以 `src/` 为准。

## 1. 定位

本服务把人类 RefSeq RNA 常驻内存，对一批 siRNA（最多 50 条）做全库近完全匹配扫描。请求可带靶基因 / accession，并用 `profile` 选择口径（`src/api.rs`、`src/search.rs`）：

- `t6b`（默认）：全长 oligo（19–23 nt）滑窗 Hamming 0–3；同时精确查找 seed（位置 2–8）互补 7-mer；按非靶计数打高/中/低（`src/score.rs`）
- `sidirect`：guide / passenger 各取位置 2–20 的 19-mer，双侧滑窗 Hamming 0–3；按转录本 min mismatch 分档；输出 `min_mismatch`、`passes_hide_less_specific` 等；不扫 seed，不输出高/中/低

匹配方式是 2-bit 打包序列上的并行线性滑窗 + Hamming（只计替换，窗口含 `N` 则跳过）。不调用外部比对程序。

## 2. 生物学约定与文献

### 2.1 反向互补位点

对每条查询序列，代码先算 `revcomp`，再与转录本窗口做 Hamming（`OligoPattern::from_full_guide` / `from_19mer`）。依据是 RISC 中 guide 通过 Watson–Crick 配对识别靶 mRNA，转录本上的位点是互补序列。

### 2.2 近匹配窗口

- `t6b`：窗口长度 = 输入 oligo 全长（校验为 19–23）。
- `sidirect`：`oligo_2_20()` 取 1-based 位置 2–20（0-based `[1, 20)`）；长度已为 19 时用整段。

19-mer / 2–20 窗口与 siDirect 2.0 近完全匹配约定一致 [1]。

### 2.3 扫描哪一条链

- `sidirect`：始终扫 guide 与 passenger；未给 `sense` 时 passenger = `revcomp(guide)`（`search_batch_sidirect`）。
- `t6b`：默认只扫 guide；`scan_sense=true` 时再扫 sense（未给则同样用 `revcomp(guide)`），结果放在响应字段 `sense` 中，不与 guide 的标签合并。

双侧近匹配与 siDirect 默认报告 guide / passenger 两侧一致；passenger 也可进入 RISC 并参与脱靶 [1,2]。

### 2.4 错配如何计数

实现：`hamming_packed`（XOR + popcount），`MAX_MISMATCH = 3`。

- `t6b`：每个 ≤3 的窗口记一次**位点**；非靶计入 `offtarget.perfect` / `mismatch_1` / `mismatch_2` / `mismatch_3`；靶计入 `on_target` 的转录本/基因集合（不进入上述 offtarget 分档）。
- `sidirect`：每条转录本对每条链只取最小 mismatch（≤3）计入分档；`offtarget_only` 不含靶，`including_on_target` 含靶；另有基因级 `*_genes`（同一基因取 isoform 间 min）。非靶最小错配写入 `min_mismatch`；无非靶 0–3 命中时为 `MIN_MISMATCH_NONE`（**4**）。`passes_hide_less_specific` = 两侧非靶 min 均 ≥ 2。

非靶 min ≥ 2 的过滤语义对齐 siDirect 2.0 默认近匹配门槛 [1]。本仓库的搜索引擎是上述线性 Hamming，不是 siDirect 线上那套预计算索引。

### 2.5 Seed（仅 `t6b`）

`seed_of_guide` 取 oligo 1-based 位置 2–8（7-mer），再取其反向互补，在转录本上做**精确**相等匹配；每条转录本最多计 1 次。靶转录本的 seed 命中不计入 `seed_transcripts` / `seed_genes`。当前 FASTA 无 UTR 坐标，因此在全长转录本上扫描。

Seed 区 2–8 与 miRNA 样脱靶的关联见 [3,4]。siDirect 2.0 用 seed–target 双链 Tm 处理该类风险 [1,2]；本服务的 `sidirect` 路径不计算 Tm，也不统计 seed 命中。

### 2.6 on-target 划分

`TargetFilter` 按 `target_gene`（基因符号，大小写不敏感）或 `target_accessions`（可带/不带版本）标记转录本是否为靶；**不缩小**扫描范围。

`t6b` 的 `offtarget.*` 与 `sidirect` 的 `offtarget_only*` 只含非靶。`sidirect` 响应顶层的 `on_target` 来自 **guide 链**扫描结果（`guide_out.on_target`）；passenger 侧的靶命中仍出现在 `hits`（`strand=passenger`）和 `including_on_target.passenger` 中。

## 3. 两种 profile（与代码一致）

| | `t6b` | `sidirect` |
|--|--|--|
| 入口 | `ScanMode::T6b` | `ScanMode::Sidirect` |
| 窗口 | 全长 19–23 | `oligo_2_20` → 19-mer [1] |
| 链 | guide；可选 `scan_sense` | 始终双侧 |
| 0–3 | 非靶**位点**计数 | 转录本 min → `[n0..n3]` |
| Seed | 精确 7-mer，进标签 | 不扫（`scan_seed=false`） |
| 过滤输出 | `specificity_label` | `min_mismatch` + `passes_hide_less_specific` |

`sidirect` 忽略请求里的 `scan_sense`；缓存键里该位固定为 0。非法 `profile` → 400。

### 3.1 T6b 标签（`specificity_label`）

只看非靶（`src/score.rs`）：

| 标签 | 条件 |
|------|------|
| 低 | `perfect > 0` 或 `mismatch_1 > 0` |
| 中 | 否则，且（`mismatch_2/3 > 0` 或 `seed_transcripts > 0`） |
| 高 | 以上皆无 |

与 siDirect 的 hide（两侧非靶 min ≥ 2）不是同一规则。

### 3.2 sidirect 响应字段（实现侧）

- `query_19mer`：实际检索的 guide / passenger 19-mer
- `offtarget_only` / `including_on_target`：转录本分档 `[n0,n1,n2,n3]`
- `offtarget_only_genes` / `including_on_target_genes`：基因分档
- `hits`：两侧 ≤3 位点合并后排序，带 `strand`（`guide` / `passenger`）
- 内部明细上限 `INTERNAL_HIT_CAP = 200`，接口再按 `max_hits_per_query` 截断；**分档与 min 按全量统计**，截断只影响 `hits` 列表

## 4. 数据与加载

- 启动要求 `data/human.1.rna.fna` … `human.16.rna.fna`（`SHARD_COUNT = 16`），由 `data/download-refseq-rna.sh` 可拉取。
- Header 解析 accession、括号内基因符号、分子类型；NM/XM/NR/XR 均入库。`includes_xm_xr` 由 accession 前缀是否出现 `XM_` / `XR_` 判定。
- 指纹：各分片文件名 + 大小 + mtime 的 SHA-256（`fasta_fingerprint`）。变化则重建 `transcriptome.bin` 并清空查询缓存。
- 内存：`packed`（2-bit）、`nmask`、`metas`。可选 `REFSEQ_RELEASE` / `data/REFSEQ_RELEASE` → `/v1/db/info.refseq_release`。

## 5. 查询与缓存

未命中缓存时：`spawn_blocking` 里对 miss 列表一次扫库；`rayon` 按转录本并行；同一批多条 query 共享外层转录本循环。

缓存键（`cache_key`）：

```text
{lib_fp}|{profile}|{target_gene}|{accessions_csv}|{scan_sense}|{guide}|{sense}
```

`cache_schema` 当前为 `sidirect-api-1`；与指纹一并校验，任一变化则删除并重建 cache 表。`id`、`max_hits_per_query` 不进键。

## 6. 模块

| 模块 | 职责 |
|------|------|
| `fasta` / `store` | 分片、指纹、打包快照 |
| `seq` | 规范化、`revcomp`、Hamming、`seed_of_guide`、`oligo_2_20` |
| `search` | `T6b` / `Sidirect` 扫描与聚合 |
| `score` | T6b 高中低 |
| `cache` / `api` | redb、HTTP |

环境变量见 `src/main.rs`：`DATA_DIR`、`INDEX_DIR`、`REDB_PATH`、`LISTEN_ADDR`、`MAX_BATCH`、`REFSEQ_RELEASE`。当前无鉴权。
