# 接入指引

下文用相对路径；把 `BASE` 换成实际服务根地址（本地默认 `http://127.0.0.1:8080`）。

对人 RefSeq RNA（NM / XM / NR / XR，约 27 万条转录本）做近完全匹配脱靶检查，一次最多 50 条。原理与文献出处见 [原理与工作方式](原理与工作方式.md)。

两种 `profile`：

| profile | 何时用 | 窗口 | 链 |
|---------|--------|------|-----|
| `t6b`（默认） | 全长 + seed 命中的初筛标签 | 全长 guide（19–23） | 默认仅 guide；`scan_sense` 可加 passenger |
| `sidirect` | 要和 siDirect 特异性检查比数字 | oligo 2–20 的 19-mer | 始终双侧 |

没走 `sidirect` 就不要说「和 siDirect 脱靶一致」。

## 1. 探活

```bash
BASE=http://127.0.0.1:8080   # 按部署修改

curl -sS "$BASE/health"
# {"status":"ok"}

curl -sS "$BASE/v1/db/info"
```

`/v1/db/info` 常见字段：`transcripts`、`bases`、`shards`、`fingerprint`、`indexed`、`includes_xm_xr`、`indexed_at`（快照 mtime，秒）、`refseq_release`（来自 `REFSEQ_RELEASE` 或 `data/REFSEQ_RELEASE`，没有则为 null）、`profiles`（窗口说明）。

## 2. 主接口

`POST /v1/offtarget/check`  
`Content-Type: application/json`

一批序列共用同一靶。搜索始终全库；`target_gene` / `target_accessions` 只把命中标成 on-target。

### 请求字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `profile` | 否 | `t6b`（默认）或 `sidirect`；其它值 400 |
| `target_gene` | 否 | 如 `PCSK9`；排除该基因全部 isoform |
| `target_accessions` | 否 | 可带或不带版本号 |
| `queries` | 是 | 1–50 条 |
| `queries[].id` | 否 | 原样回传；缺省 `q1`… |
| `queries[].guide` | 是 | 19–23 nt，`A/C/G/T/U` |
| `queries[].sense` | 否 | `sidirect` 下会用（缺省 `revcomp(guide)`）；`t6b` 仅 `scan_sense=true` 时用 |
| `scan_sense` | 否 | 默认 false；**只对 t6b 有效** |
| `max_hits_per_query` | 否 | 明细条数，默认 50，范围 1–200；不影响计数 |

两靶字段都空时，靶自己的 perfect match 也会算进脱靶。设计管线里应带 `target_gene`。

### 示例：t6b（默认）

```bash
curl -sS -X POST "$BASE/v1/offtarget/check" \
  -H 'Content-Type: application/json' \
  -d '{
    "target_gene": "PCSK9",
    "target_accessions": ["NM_174936.4"],
    "queries": [
      {"id": "PCSK9_21mer_792_812", "guide": "ATAAACTCCAGGCCTATGAGG"}
    ]
  }'
```

### 示例：sidirect

```bash
curl -sS -X POST "$BASE/v1/offtarget/check" \
  -H 'Content-Type: application/json' \
  -d '{
    "profile": "sidirect",
    "target_gene": "PCSK9",
    "target_accessions": ["NM_174936.4"],
    "queries": [
      {
        "id": "PCSK9_21mer_792_812",
        "guide": "ATAAACTCCAGGCCTATGAGG",
        "sense": "CCTCATAGGCCTGGAGTTTAT"
      }
    ]
  }'
```

`sidirect`：各链取 1-based 位置 2–20（21-mer 去两端；19-nt 用整条），在转录本上搜反向互补，Hamming 0–3，无 gap。

### 响应：t6b

```json
{
  "results": [
    {
      "id": "PCSK9_21mer_792_812",
      "guide": "ATAAACTCCAGGCCTATGAGG",
      "length": 21,
      "cached": false,
      "profile": "t6b",
      "specificity_label": "中",
      "on_target": { "transcripts": 18, "genes": 1 },
      "offtarget": {
        "perfect": 0,
        "mismatch_1": 0,
        "mismatch_2": 0,
        "mismatch_3": 20,
        "seed_transcripts": 49357,
        "seed_genes": 7011
      },
      "hits": [
        {
          "accession": "NM_174936.4",
          "gene": "PCSK9",
          "mismatches": 0,
          "position": 1082,

```

要点：`offtarget.perfect`…`mismatch_3` 是非靶**位点**计数；`hits[].position` 为 1-based；`sense` 仅在 `scan_sense=true` 时出现。

```json

      "passes_hide_less_specific": true,
      "on_target": { "transcripts": 1, "genes": 1 },
      "offtarget_only": {
        "guide": [0, 0, 5, 12],
        "passenger": [0, 0, 0, 0]
      },
      "including_on_target": {
        "guide": [1, 0, 5, 12],
        "passenger": [0, 0, 0, 0]
      },
      "offtarget_only_genes": {
        "guide": [0, 0, 3, 8],
        "passenger": [0, 0, 0, 0]
      },
      "including_on_target_genes": {
        "guide": [1, 0, 3, 8],
        "passenger": [0, 0, 0, 0]
      },
      "hits": [
        {
          "accession": "NM_174936.4",
          "gene": "PCSK9",

          "position": 1083,

```

sidirect 不返回 `specificity_label` 和 seed 计数。`min_mismatch` 无非靶 0–3 命中时为 **4**。`passes_hide_less_specific` 表示两侧非靶 min ≥ 2。分档数组是 `[n0, n1, n2, n3]`，按转录本（或基因）的 **min** mismatch 互斥入档。

### 哪一列含靶

| 字段 | 单位 | 含靶？ | 和 siDirect 的对应 |
|------|------|--------|-------------------|
| t6b `offtarget.perfect`…`mismatch_3` | 转录本位点 | 否 | 无直接对应 |
| t6b `on_target` | 转录本 / 基因 | 只含靶 | — |
| sidirect `offtarget_only.*` | 转录本 min-mm | 否 | 非靶 0–3 |
| sidirect `including_on_target.guide` | 同上，含靶 | 是 | `0(+)…3(+)` |
| sidirect `including_on_target.passenger` | 同上 | 是 | `0(−)…3(−)` |
| `*_genes` | 基因 min-mm | 同左 | TSV 若按基因计，用这组 |
| `min_mismatch.*` | 非靶最小错配；无命中=4 | 否 | 页面 min mismatch |
| `passes_hide_less_specific` | 两侧 min ≥ 2 | — | 默认 hide less specific |

`results` 顺序与请求 `queries` 一致。

### T6b 标签（仅 `profile=t6b`）

| 标签 | 条件（只看非靶） |
|------|------------------|
| 高 | 无 0/1-mm，且 seed 转录本 = 0 |
| 中 | 无 0-mm，但有 2–3 mm 或 seed > 0 |
| 低 | 有 0-mm 或 1-mm |

## 3. 错误

失败时 body：`{"error":"..."}`。

| 情况 | 状态 |
|------|------|
| `queries` 空或超过 50 | 400 |
| `profile` 非法 | 400 |
| 长度不是 19–23，或含非法碱基 | 400 |
| `max_hits_per_query` 不在 1–200 | 400 |
| JSON 解析失败 | 400 |
| 内部错误 | 500 |

## 4. 约定

- **超时**：未缓存时单条数百毫秒级；sidirect 扫双侧。50 条一批建议 ≥ 30 s。
- **缓存**：键含库指纹、profile、靶、scan_sense、guide、sense。schema 变更会清空旧缓存，上线后第一次全是 miss 属正常。`id` / `max_hits_per_query` 不进键。
- **碱基**：去空白、大写、`U`→`T`；搜的是反向互补位点。
- **鉴权**：无；不要对公网裸奔。

## 5. Python

```python
import requests
import os

BASE = os.environ.get("OFFTARGET_BASE", "http://127.0.0.1:8080")

def check_t6b(guides, target_gene, target_accessions=None, timeout=30):
    payload = {
        "profile": "t6b",
        "target_gene": target_gene,
        "target_accessions": target_accessions or [],
        "queries": [{"id": qid, "guide": seq} for qid, seq in guides],
    }
    r = requests.post(f"{BASE}/v1/offtarget/check", json=payload, timeout=timeout)
    r.raise_for_status()
    return r.json()["results"]

def check_sidirect(guides, target_gene, target_accessions=None, timeout=30):
    # guides: (id, guide) 或 (id, guide, sense)
    queries = []
    for row in guides:
        q = {"id": row[0], "guide": row[1]}
        if len(row) > 2 and row[2]:
            q["sense"] = row[2]
        queries.append(q)
    payload = {
        "profile": "sidirect",
        "target_gene": target_gene,
        "target_accessions": target_accessions or [],
        "queries": queries,
    }
    r = requests.post(f"{BASE}/v1/offtarget/check", json=payload, timeout=timeout)
    r.raise_for_status()
    return r.json()["results"]
```

每批 ≤ 50。同一靶、同一 profile 下重复序列会走服务端缓存。
